# apps/

Next.js applications. Each app is independently deployable to Vercel.

- **`web/`** — marketing site (vought.com)
- **`app/`** — product app (app.vought.com) — has `/live` (the hero screen)
- **`teams/`** — manager dashboard (Teams plan)

All apps share `packages/design-system`, `packages/motion`, and `packages/ui`.
