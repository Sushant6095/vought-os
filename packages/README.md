# packages/

Shared workspace packages. Consumed by every app.

- **`design-system/`** — tokens (color, type, spacing, motion), Tailwind config, primitives
- **`motion/`** — the four signature motions + timing constants
- **`ui/`** — shared React components (Button, Card, Pill, Modal, etc.)
- **`types/`** — shared TypeScript types and Zod schemas

Built by `design-system-architect` agent in Phase 1.
