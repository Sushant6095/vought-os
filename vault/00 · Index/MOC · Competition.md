# Competition MOC

> Every named competitor with our differentiation strategy versus each.

## The category map

**Enterprise real-time agent assist** (B2B, contact center)
- [[Cresta]] — $1.6B valuation, $52M ARR, the leader. Desktop overlay only.
- Balto — $60M+ raised. Same form factor.
- [[Observe AI]] — $214M raised. Same form factor.

**Post-call conversation intelligence**
- [[Gong]] — $4.5B / $500M ARR. Post-call analytics. Adjacent.
- Chorus.ai — acquired by ZoomInfo ($575M).
- Wingman — acquired by Clari.

**Voice infrastructure**
- Bland.ai — voice agent API.
- Retell — voice agent API.
- Vapi — voice agent API.

**Interview cheat**
- Cluely — $20.3M raised, brand-poisoned. Pivoted to Otter clone.
- Final Round AI — 10M users claim, $6.88M seed.

**Dating "rizz"**
- Rizz, YourMove, Keys — all text-based, none in voice.

**Translation earbuds (Apple ate this)**
- Timekettle, Vasco — killed by AirPods Live Translation Sept 2025.

**Meeting AI (post-call)**
- Otter ($100M ARR), Granola ($1.5B), Fathom, Fireflies.

## Our differentiation (the 5-axis test)

| Axis | Cresta | Cluely | Vought |
|---|---|---|---|
| Surface | desktop overlay | screen overlay | **in-ear (AirPods)** |
| Voice | generic TTS | text only | **user's cloned voice** |
| Latency | <200ms | n/a | **<1s end-to-end** |
| Use case | call center only | interview only | **personal + revenue + receptionist** |
| Brand | enterprise-soft | provocative-consumer | **calm precision** |

## The Apple risk

Apple Live Translation on AirPods (shipped Sept 2025) proves Apple is willing to do "AI processing other people's voices in real time." 18-month window before Apple ships a horizontal API. We need to win the verticals before then.
