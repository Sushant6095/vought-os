# Wave 5 · /security page

## What was done

Built `apps/web/app/security/page.tsx` per `VOUGHT-DESIGN-BLUEPRINT.md` §11 and §4.1 (`/security` route spec). Single-file page following the buyer's-confidence-builder shape — calmly written, longer paragraphs, real status on every claim.

### Sections shipped (in order)

1. **Hero** — *"Built for the conversations that can't leak."* Subhead reframes the ephemeral-by-default posture. Metric strip shows `0s` retention, `3` residency regions, `5` named sub-processors, `412ms` median latency. Mono digits on every number.
2. **Executive statement** — Founder-signed (Adithya Rao, Co-founder & CEO) ~200-word paragraph. Declarative voice: *"Vought is a real-time system. It listens to your live audio for the length of a conversation and forgets it as soon as that conversation ends. This is not a feature flag. It is the default."* No hedging, no jargon, no AI-powered.
3. **Certifications grid** — Four cards in a 2×2 / 4-up grid:
   - SOC 2 Type II · *In progress* · target Q3 2026 (Drata + Prescient Assurance)
   - HIPAA · *Aligned* · BAA on Receptionist Enterprise
   - GDPR · *Live* · DPA at vought.com/legal/dpa
   - ISO 27001 · *In progress* · target Q4 2026
   Status pills colored amber (in progress), emerald (live), or white (aligned) with breath-cadence pulse where appropriate.
4. **Architecture data flow** — Five-node diagram (Operator device → ElevenLabs STT → Echo Engine → LLM → ElevenLabs TTS) using the same `wire-active` SVG keyframe and emphasis pattern as `ArchitectureDiagram`. Each leg annotated with retention class (`In memory only`, `Transit only`, `Session memory`, `Inference only`) and a one-line detail. Amber summary block at the bottom: *"End-to-end retention for an unmodified Vought session is · 0s after the call ends."*
5. **Sub-processor table** — Five rows: ElevenLabs, OpenAI, Anthropic, AWS, Cloudflare. Columns: vendor · purpose · data type · region. Region in mono. "Last updated 2026-05-26" footer linking `trust@vought.com`.
6. **Data residency** — Three cards: `US`, `EU`, `IN`. Each with cloud provider (AWS us-east-1, eu-central-1, ap-south-1) and a single paragraph on residency policy. Immutable-at-creation language to set legal expectation.
7. **Public contacts** — Three cards: `security@vought.com`, HackerOne bug bounty ($100–$5,000), Trust Center placeholder URL (`https://trust.vought.com`). Each links out, no triage forms.
8. **CTA strip** — *"Reviewing Vought for your team?"* Two CTAs: Download one-pager (PDF placeholder) · Talk to legal (mailto). Three-bullet checklist below the headline: SIG Lite + CAIQ questionnaire, pentest summary, sub-processor subscription. Amber orb at the bottom mirrors the landing CTA's shape but without the `data-canvas-shift` mutation (that's reserved for the landing's exit moment).

## Tokens and motion compliance

- Every color is a token class (`text-white/X`, `bg-surface-dark`, `border-accent-amber/X`, `text-live-emerald`, `text-marketing-ink`, `bg-accent-amber`) — no raw hex outside the shared `#0C0C0E` darker-surface (which already appears in `ArchitectureDiagram` and `TrustGrid` as the section alternate).
- Every transition uses `duration-quick ease-quick` from the design-system preset.
- Every section reveal uses `.reveal` with delays drawn from the canonical 80 / 240 / 360 / 480 ms scale. No bespoke timings introduced.
- `pulse-amber` and `pulse-emerald` reuse the canonical 2000 ms breath cadence.
- `wire-active` SVG animation reuses the existing keyframe with the same 240 ms stagger as `ArchitectureDiagram`.

## Brand voice audit

- No "AI-powered", "supercharge", "revolutionize", "10x", or "game-changer" anywhere.
- All sentences declarative. Headlines 3–8 words. Body sentences mostly 12–22 words.
- All metric numbers in mono (`0`, `3`, `5`, `412ms`, `· 0s`).
- Named specifics: Drata, Prescient Assurance, HackerOne, AWS us-east-1 / eu-central-1 / ap-south-1, gpt-4o-mini, Claude Haiku, AWS Bedrock, SIG Lite, CAIQ, HIPAA BAA, Article 28 DPA, SCCs.
- Honest status — "In progress" for SOC 2 Type II and ISO 27001 rather than displaying badges we have not earned.
