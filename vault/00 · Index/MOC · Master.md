## How to use

When picking up Vought work cold:
1. Read `CLAUDE.md` (top-level project context)
2. Read this MOC
3. Read the three most recent session logs
4. Read the domain MOC most relevant to your task
5. Begin

When finishing work:
1. Update the relevant note(s)
2. Add an ADR if you made a non-trivial decision
3. Write a session log
