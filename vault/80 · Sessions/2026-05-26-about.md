# Wave 5 · /about

## What was done

Built `apps/web/app/about/page.tsx` per VOUGHT-DESIGN-BLUEPRINT.md §11 (About page). Narrative-led, single-column, quiet. Seven sections in order, ~1500vh total, dark cinematic feel matching the landing page tone.

## Sections shipped

1. **Hero** — full-bleed CSS-art waveform (SVG path + 70 procedurally-seeded hairline bars + amber radial gradient). No photo, no stock. `label-small` amber eyebrow *"Vought · founded 2025"*, `display-3xl` headline *"A voice in your ear."*, 22-word lede. Narrow container.
2. **The story** (~1200 words) — Three-act framing reused from `vault/10 · Strategy/Three-Act Narrative.md` but rewritten as the company origin story. Personal voice. Explicitly acknowledges Cyrano de Bergerac. Each act has an eyebrow label and three paragraphs of body. Staggered reveal at 0 / 80 / 240ms.
3. **Our point of view on voice AI** — Four ~50-word paragraphs on consent, operator vulnerability, coaching-vs-cheating, AI invisibility. Numbered, left-border hairline accent, staggered reveal 0 / 80 / 240 / 360ms.
4. **The team** — Six members. Initialed circular avatars (no photos — radial amber tint backplate over surface-dark). Photo · name · role · one-line bio. 3-col on desktop, 2-col tablet, 1-col mobile. Roles span CEO/CTO/Design/Research/Revenue/Founding Eng.
5. **Investors** — Single subdued row of five typeset wordmarks (Sequoia, a16z, Founders Fund, South Park Commons, Conviction). Each in distinctive type treatment (mirroring CustomerLogos.tsx vocabulary). 30% white. Hairline band top + bottom.
6. **Where we are** — Two cities, two-column. San Francisco (HQ, 548 Market Street) + Bangalore (Research, Domlur II Stage). Each with `mono` local time + amber dot prefix callsign. `<address>` semantic.
7. **CTA** — *"Want to work with us?"* centered. Amber `pill-cta` → `/careers` + outline → `/contact`. Re-uses the orb-amber ambient orb from CTAStrip without triggering the canvas-shift.

## Reuse decisions

- **Hero pattern** — pulled directly from `Hero.tsx`: `label-small` amber eyebrow + `display-3xl` headline + `display-2xl` section heads + `reveal` motion stagger 80/240ms. Did not import Hero because it has a two-column dashboard layout that does not fit the narrative single-column rhythm.
- **CustomerLogos vocabulary** — investor row uses the same "typeset wordmarks with distinct identities, 30% white, hairline band" pattern. Did not import CustomerLogos because the labels and styles differ.
- **CTAStrip orb** — closing CTA uses the same amber orb + narrow container + amber `pill-cta` + bordered secondary, without the IntersectionObserver canvas-shift (which is reserved for the landing).
- **Container primitives** — `Container width="narrow"` (720px) for the story / POV / offices / CTA. `Container width="marketing"` (1180px) for the team grid only.
- **Footer + NavPill** — already mounted in root layout. No import needed. Footer already links `/about` (Company column).

## Brand voice compliance

- All sentences declarative. No hedging, no "AI-powered," no "supercharge," no "revolutionize," no "10x."
- Specific named references: Cyrano de Bergerac, Speech Engine, 412ms whisper, 180ms STT, 250ms TTS, Series A pitch.
- Latency formatted with the `mono` brand callsign — local times rendered as `· 11:32 PT` and `· 00:02 IST` in amber.
- No exclamation marks. No emoji. No confetti language.
- The four-rules POV uses cold declarative construction (*"The operator is vulnerable."*) not consultative softeners.

## Motion compliance

- All section reveals use the global `.reveal` IntersectionObserver hook from `MarketingRoot`.
- All hover transitions use `duration-quick ease-quick` tokens (or none) — no raw values.
- Stagger delays: 0 / 80 / 160 / 240 / 320 / 360 / 400ms — within canonical motion tokens.
- Hero waveform is static SVG. No JS animation. Reduced-motion safe by construction.

## Accessibility

- `<address>` for both office locations.
- `aria-labelledby` on every section with a heading. `aria-label` on the investor strip.
- Hero is `<h1>`. Each section is `<h2>`. Each story act / POV item / team member uses subordinate elements without breaking heading hierarchy.
- Avatar initials are `aria-hidden` since the visible name immediately follows.
- Hero SVG marked `role="presentation"` — purely decorative.
- Color contrast: text white/55 minimum (≥ AA on canvas-dark), eyebrows on accent-amber (≥ AA).

## Responsive

- Story / POV / Offices / CTA: narrow column (720px max) — single column at all breakpoints.
- Team grid: 1-col @ 375 → 2-col @ 768 → 3-col @ 1024+.
- Investors: wrap with `gap-x-14 gap-y-8` — flows naturally 375 → 1440.
- Hero waveform: `h-[60vh]` + `preserveAspectRatio="none"` → stretches across the canvas at every breakpoint.

## Scope kept

- Only `apps/web/app/about/page.tsx` touched.
- No edits to packages/ (design-system, motion, ui).
- No edits to services/ or apps/app/.
- No edits to nav, footer, or existing marketing components.
- No metadata.ts file — `generateMetadata()` exported from page.tsx as the simpler option.
